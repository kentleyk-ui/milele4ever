Fichier Description Ordre

🚀 Méthodes de Restauration

Méthode 1 : Via Dashboard Supabase (Recommandé)
✅ Le plus simple et le plus sûr • Pas de dépendances • Interface visuelle
  1. Allez sur https://supabase.com/dashboard
  2. Sélectionnez votre projet milele4ever
  3. Allez dans l'onglet SQL Editor
  4. Copiez le contenu de 001-create-tables.sql et exécutez
  5. Répétez pour 002-rls-policies.sql
  6. Répétez pour 003-service-request-full.sql
Méthode 2 : Via Script Node.js
⚡ Rapide et automatisé • Requiert Node.js
Exécutez cette commande depuis la racine du projet :
npm run db:restore
Méthode 3 : Via Script Python
🐍 Alternatif • Requiert Python 3.8+ et psycopg2
npm run db:restore:py
Ou manuellement :
python3 scripts/restore-backup.py

⚙️ Configuration Requise

⚠️ Important : Créez un fichier .env.local à la racine du projet avec vos variables Supabase
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co SUPABASE_SERVICE_ROLE_KEY=votre_clé_secrète_ici
Où trouver ces valeurs :
  1. Allez sur https://supabase.com/dashboard
  2. Sélectionnez votre projet
  3. Cliquez sur Settings → API
  4. Copiez Project URL et Service Role Secret

📊 Structure de Données

Votre sauvegarde restaurera 13 tables :
  • Profiles (utilisateurs)
  • Memorials (pages commémoratives)
  • Memorial Members (permissions)
  • Posts (publications)
  • Media (photos/vidéos)
  • Timeline Events (événements)
  • Family Relationships (généalogie)
  • Conversations (messagerie)
  • Conversation Participants
  • Messages
  • Notifications
  • Service Requests (demandes funéraires)
  • Candles (bougies virtuelles)

✅ Après la Restauration

Vérifiez que tout s'est bien passé en exécutant cette requête SQL :
SELECT table_name FROM information_schema.tables WHERE table_schema = 'public' ORDER BY table_name;

Vous devriez voir les 13 tables listées ci-dessus.
