🚀 DÉMARRAGE RAPIDE
───────────────────────────────────────────────────────────────────────────────

1. CRÉEZ LE FICHIER .env.local

   Copiez .env.local.example en .env.local et remplissez:
   
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=votre_clé_secrète

2. CHOISISSEZ VOTRE MÉTHODE

   OPTION A: Interface Web (Aucune dépendance)
   ├─ Ouvrez: scripts/restore-gui.html
   └─ Suivez les instructions

   OPTION B: Command Line (Node.js)
   ├─ npm run db:restore

   OPTION C: Command Line (Python)
   ├─ npm run db:restore:py

   OPTION D: Dashboard Supabase (Plus sûr)
   ├─ https://supabase.com/dashboard
   ├─ SQL Editor
   └─ Copiez/exécutez les 3 fichiers .sql dans l'ordre
