🚀 COMMENT UTILISER

OPTION 1 : PLUS SIMPLE (via npm)
─────────────────────────────────────
npm run db:restore

Prérequis: Node.js installé + variables d'environnement dans .env.local


OPTION 2 : PYTHON
─────────────────────────────────────
npm run db:restore:py

Prérequis: Python 3.8+ + psycopg2-binary


OPTION 3 : INTERFACE WEB
─────────────────────────────────────
Ouvrez le fichier: scripts/restore-gui.html dans votre navigateur
Pas de dépendances requises !


OPTION 4 : DASHBOARD SUPABASE (Recommandé pour débutants)
─────────────────────────────────────
1. Allez sur https://supabase.com/dashboard
2. Sélectionnez votre projet "milele4ever"
3. Allez dans SQL Editor
4. Copiez/exécutez les 3 fichiers .sql dans l'ordre


OPTION 5 : EXPORTER VOS DONNÉES D'ABORD
─────────────────────────────────────
npm run db:export

Crée un backup-DATE.json avec toutes vos données actuelles

═══════════════════════════════════════════════════════════════════════════════

⚙️ CONFIGURATION REQUISE

Créez un fichier .env.local à la racine du projet avec:

  NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
  SUPABASE_SERVICE_ROLE_KEY=votre_clé_secrète_ici

Où trouver ces valeurs:
  1. https://supabase.com/dashboard
  2. Sélectionnez votre projet
  3. Settings → API
  4. Copiez Project URL et Service Role Secret

⚠️  Ne partagez JAMAIS votre SUPABASE_SERVICE_ROLE_KEY publiquement!

📊 STRUCTURE DE BASE DE DONNÉES

13 tables seront restaurées:

  UTILISATEURS & PROFILS:
  ├─ profiles (utilisateurs)
  
  MEMORIALS (pages commémoratives):
  ├─ memorials (pages principales)
  ├─ memorial_members (permissions)
  ├─ posts (publications)
  ├─ media (photos/vidéos)
  ├─ timeline_events (événements de vie)
  ├─ family_relationships (généalogie)
  ├─ candles (bougies virtuelles)
  
  MESSAGERIE:
  ├─ conversations (fils de discussion)
  ├─ conversation_participants (participants)
  ├─ messages (messages)
  
  NOTIFICATIONS & SERVICES:
  ├─ notifications (alertes)
  ├─ service_requests (demandes funéraires)

═══════════════════════════════════════════════════════════════════════════════

🔒 SÉCURITÉ

✅ Row Level Security (RLS) activé sur toutes les tables
✅ Les utilisateurs ne voient que leurs propres données
✅ Les memorials publics sont visibles par tous
✅ Les modifications nécessitent les bonnes permissions
✅ Les notifications ne sont visibles que par le destinataire

✅ VÉRIFICATION APRÈS RESTAURATION

Exécutez cette requête SQL pour vérifier que tout est en place:

  SELECT table_name 
  FROM information_schema.tables 
  WHERE table_schema = 'public'
  ORDER BY table_name;

Vous devriez voir les 13 tables listées ci-dessus.
