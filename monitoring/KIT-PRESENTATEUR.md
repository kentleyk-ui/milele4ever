# Kit Presentateur - Formation Monitoring Milele

## Objectif

Ce kit te donne tout le necessaire pour animer une session de 90 minutes:

1. Slides pretes
2. Script oral minute par minute
3. Feuille d'emargement
4. Quiz et grille d'evaluation

## Fichiers du kit

- monitoring/SLIDES-FORMATION.md
- monitoring/SCRIPT-ORAL-90MIN.md
- monitoring/FEUILLE-EMARGEMENT.md
- monitoring/QUIZ-EQUIPE.md
- monitoring/CHECKLIST-COMPETENCES.md

## Preparation J-1

1. Verifier acces Vercel (logs + deploys)
2. Verifier scripts locaux:
   - scripts/monitor-prod.ps1
   - scripts/monitor-prod-json.ps1
   - scripts/monitor-report-24h.ps1
3. Preparer un terminal PowerShell ouvert a la racine du projet
4. Preparer les liens Smartsheet (si demo API)

## Ouverture de session (2 min)

Message recommande:

"Aujourd'hui, l'objectif est que chacun puisse surveiller la prod, diagnostiquer un incident et executer les actions minimales de remediations sans blocage."

## Livrable attendu fin de session

- Chaque participant execute 1 check complet
- Chaque participant lit 1 rapport 24h
- Chaque participant suit la sequence incident (simulation)
- Evaluation completee via checklist competences

## Cloture

- Collecter feuilles d'emargement
- Noter scores quiz
- Planifier coaching pour profils < 12/15
